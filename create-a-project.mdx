# Create a Project

Everything in EdgeStudio happens inside a project, so creating one is your first step. This page shows where to start and what each part of the **New Project** dialog does.

---

## Open the New Project dialog

1. Sign in and open the [Dashboard](/docs/dashboard).
2. Check the workspace switcher: the project is created in whichever workspace you're in, **Personal** or an **Organization**.
3. In the **Projects** card, click **New project** (the button with the **+** icon in the top-right corner of the card).

The **New Project** dialog opens.

---

## The New Project dialog

The dialog has three fields: a task type, a name, and an optional description.

### Task Type

Task Type is required. Pick one of the cards:

| Task type | What it's for |
| --- | --- |
| **Image Classification** | Categorize images into predefined classes |
| **Audio Anomaly Detection** | Detect abnormal patterns and outliers |
| **Vibration Anomaly Detection** | Detect abnormal vibration patterns in machinery |
| **Object Detection** | Locate and identify objects in images. Marked **Coming soon** for now, so it can't be selected yet. |

The selected card is highlighted in blue. The task type decides which training options and metrics you'll see later, and it **can't be changed after the project is created**, so choose the one that matches what you want to build.

### Project Name

Project Name is required. Use between 3 and 128 characters. A counter under the field shows how much of the 128-character limit you've used.

### Description

Description is optional and can be up to 256 characters. A counter under the field shows how much of the limit you've used.

---

## Create the project

At the bottom of the dialog you have two buttons:

- **Cancel** closes the dialog without creating anything.
- **Create Project** creates the project. It stays disabled until you've selected a task type and entered a name of at least 3 characters.

While the project is being created the button reads **Creating…**. When it's done, the dialog closes, a confirmation message tells you whether the project was created in your personal or organization workspace, and the new project appears in the **Projects** table.

---

## What's next

Click your new project in the Projects table to open it. From there you can work on its [Devices](/docs/devices), [Datasets](/docs/datasets), [Training](/docs/training), and [Deployment](/docs/deployment). For managing projects afterwards (editing or deleting them), see [Project](/docs/projects).
